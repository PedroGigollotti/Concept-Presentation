7 · Advanced relative clauses

Adding detail without breaking the sentence.

ACCESS

Goal. Read the update and notice the moves in bold. You are spotting the pattern here, not producing it yet.

Dana (account lead) Any movement on the renewal?

Felix (sales) The client, who signed last month, wants a call this week. The proposal, which we sent Monday, is still under review.

Dana Any concerns from their side?

Felix Not really. The vendor, whose pricing we renegotiated, is on board. We hit the deadline, which surprised everyone.

Dana Great, keep me posted on the call.

ANALYSIS

Goal. Learn how non-defining relative clauses add extra detail without breaking the main claim, and how a sentential which can comment on a whole event.

The structure

A relative clause lets you attach extra detail to a noun without starting a new sentence, and the comma decides how essential that detail is. A non-defining relative clause, set off by commas, adds background the sentence doesn't strictly need. A sentential relative clause, using which after a comma, steps back even further and comments on the entire clause that came before it, not just the last noun in it.

Non-defining relative clause

Form
noun, who or which + clause, continues
Meaning
extra, non-essential detail about the noun
Use it to
give background without interrupting the main claim
The client, who signed last month, wants a call this week.

Sentential relative clause

Form
main clause, which + comment
Meaning
a comment on the whole situation just described, not one noun
Use it to
add an evaluative aside about an entire event
We hit the deadline, which surprised everyone.

Watch out

Don't use "that" after a comma. "That" only introduces defining clauses, with no comma. "The client, that signed last month," is wrong; use "who."

Watch for ambiguous sentential "which." "She sent the report to the client, which was overdue" leaves it unclear whether the report or the client was overdue. Rewrite so only one reading is possible.

American / British English.

"That" versus "which." American style guides strictly reserve "that" for defining clauses and "which" for non-defining ones. British usage is looser and allows "which" in defining clauses too. This book follows the stricter American convention.

The moves

Same structure in every line. The highlighted slot changes; the comma marks the extra detail as non-essential.

  • The client, who [signed last month / renewed early], wants a call this week.
  • We hit the deadline, which [surprised everyone / nobody expected].
  • The vendor, whose [contract / pricing] we renegotiated, is on board.
  • The proposal, which [we sent Monday / just went out], is still under review.
  • The error, which [took days to trace / nobody could explain], is finally fixed.

Where each move sits

The extra fact folds into the main claim without competing with it for attention.

Why this works

Business writing rewards density, but density without clarity just produces run-on sentences that lose the reader. The comma is doing real work here: it tells the reader "this detail is useful but skippable" so the main claim stays visible even inside a longer sentence. A sentential "which" goes one step further, letting you react to an entire event in the same breath you report it, which is exactly how people actually think and talk about outcomes.
