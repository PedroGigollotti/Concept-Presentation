ANALYSIS
------------------------------------------------------------------------
Goal. Learn to say there is some. Then learn to ask and to say no.

THE STRUCTURE
English has two words for an amount it does not count. Say “some” when the answer is yes: “There is some coffee”. Say “any” when you ask: “Is there any coffee?” Say “any” when the answer is no: “There isn't any coffee”. The words never change for one thing or for more than one.
   | some (yes)  ·  Form: some + the thing  ·  Meaning: There is an amount. You do not count it.  ·  Use it to: say the kitchen has it  ·  example: There is some coffee.
   | any (asking)  ·  Form: Is there any + the thing?  ·  Meaning: You do not know. It is a question.  ·  Use it to: ask what the kitchen has  ·  example: Is there any milk?
   | any (no)  ·  Form: isn't any / aren't any + the thing  ·  Meaning: There is none of it.  ·  Use it to: say the kitchen has none  ·  example: There isn't any milk.
   | some (an offer)  ·  Form: Would you like some + the thing?  ·  Meaning: Not a question about the room. It is a cup, offered.  ·  Use it to: offer somebody something  ·  example: Would you like some coffee?

WATCH OUT

   [ An offer is not a question about the room. “Is there any coffee?” asks about the kitchen. You answer “Yes, there is.” “Would you like some coffee?” offers you a cup. You answer “Yes, please.” Answer the second one with “× Yes, there is”. Nobody pours you a coffee. One negative is enough. Say “There isn't any milk” or “There is no milk.” Never both: “× There isn't no milk.” ]

   [ Two ways to say it. Unit 8 has “There is no milk”. This unit has the other one: “There isn't any milk”. Both are correct. The second one is the one people say in a kitchen. ]

YES, ASKING, AND NO
   (figure) One word for yes. One word for asking and for no.

WHY THIS WORKS
In your language one word does all three jobs. Often it is not there at all. English splits them. Say the wrong one and nobody stops you. But say “yes, there is” to a man with a coffee pot. He pours nothing.
