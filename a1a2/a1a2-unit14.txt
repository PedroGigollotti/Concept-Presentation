ANALYSIS
------------------------------------------------------------------------
Goal. Learn the words for what a thing is like. Then learn where to put them.

THE STRUCTURE
English puts the describing word IN FRONT of the thing. Say “a new file”. Your language puts it after. After “is” and “are” it stands on its own: “The file is new”. And it never changes: “one new file”, “two new files”.
   | before the noun  ·  Form: a / an + word + thing  ·  Meaning: Which one you mean.  ·  Use it to: pick one thing out of several  ·  example: a new file
   | after is and are  ·  Form: thing + is / are + word  ·  Meaning: What it is like.  ·  Use it to: say something about a thing  ·  example: The file is new.
   | it never changes  ·  Form: the same word for one and for many  ·  Meaning: No -s, ever.  ·  Use it to: say it about two things  ·  example: two new files

WATCH OUT

   [ Before the thing, not after it. Say “a new file.” Never say “× a file new.” This unit exists for that mistake. It never takes an -s. Say “two big rooms.” Never say “× two bigs rooms.” The thing takes the “-s”. The word in front of it does not. Watch a and an. Unit 5's rule works on the word that comes NEXT. Say “an old file” and “a new file”. The describing word decides it now. ]

   [ Two in a row. You can use two: “a thin blue file”. What it is LIKE comes first and the color comes last. Two is enough at work. ]

THE MOVES
Ready-made lines for picking one thing out. Change only the words in blue.
   - It is a [new] file.
   - The file is [new].
   - Not the [old] one.
   - Which [room] is free?
   - The [small] one.

THE TWO PLACES IT CAN STAND
The same word, in front of the thing or after “is”.
   (figure) Both are correct. Neither one ever takes an -s.

WHY THIS WORKS
At work you almost never name a thing. You pick one out of several. The word in front is how you do it. Say it after and everybody still understands you. Miss it and you carry the wrong file to a client.

B. Spot and fix the error
   Each sentence has one mistake. Write it correctly.
   1. × It is a file new.
      -> It is a new file.
   2. × They are rooms big.
      -> They are big rooms.
   3. × We have two smalls rooms.
      -> We have two small rooms.
   4. × The box is a heavy.
      -> The box is heavy.
   5. × It is a old file.
      -> It is an old file.

C. Put the word in
   Write the sentence again with the word in brackets.
   1. It is a room. (big)
      -> It is a big room.
   2. The coffee is ready. (hot)
      -> The hot coffee is ready.
   3. They are files. (new)
      -> They are new files.
   4. It is a cup. (broken)
      -> It is a broken cup.
   5. Bring a box. (empty)
      -> Bring an empty box.
   6. It is an office. (small)
      -> It is a small office.

D. Which order?
   Choose the English.
   1. It is ( a new file / a file new ).
      -> a new file
   2. They are ( two big rooms / two bigs rooms ).
      -> two big rooms
   3. The box ( is heavy / heavy is ).
      -> is heavy
   4. It is ( an old cup / a old cup ).
      -> an old cup
   5. ( The small room / The room small ) is free.
      -> The small room
   6. They are ( dirty cups / cups dirty ).
      -> dirty cups

E. What is it like?
   Read the word. Choose what it means.
   1. heavy
      -> b. hard to lift
   2. empty
      -> c. with nothing inside
   3. full
      -> d. with no room left inside
   4. broken
      -> a. in pieces, and it does not work
   5. dirty
      -> e. not clean
   6. hot
      -> f. at a high temperature

      a. in pieces, and it does not work
      b. hard to lift
      c. with nothing inside
      d. with no room left inside
      e. not clean
