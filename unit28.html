28 · RUN, CALL, and WORK

The three workplace verbs: one shared set of particles, three ways to use it.

ACCESS

The last clinic, and it runs three verbs at once. Watch how the same few particles move run, call, and work differently. One phrase, run with, is never taught here. Predict it from the particle before you read on.

A marketing team choosing a campaign, with legal, the budget, and the calendar all pushing back.

Nadia Before we commit, let me run the bold concept by legal. They flagged the last one.

Theo Smart. We ran into a trademark issue on the spring campaign. Don't want a repeat.

Nadia Right. And we're running out of budget this quarter, so whatever we pick has to count.

Theo Agreed. If the numbers don't hold, we call off the paid push and go organic.

Nadia Fine. But someone has to call out the unrealistic timeline. Two weeks isn't enough.

Theo True. Let's work out a phased plan, and I'll run with the teaser while we work on the rest.

ANALYSIS

This last clinic runs three verbs side by side, the three that do the most work in a professional day: run, call, and work. Watch the particle out in particular: it shows up on all three and means something different every time.

Run is about motion and management: run an idea by someone, run into a problem, run out of a resource. Call is about voice and summons: call off an event, call out a problem. Work is about effort and result: work out a solution, work on a task.

Three verbs, one shared set of particles. Notice out on all three, meaning something different each time.

Watch out. Run out and run out of differ: run out means be used up; run out of means have no more of a thing. And call out has two senses: publicly name what's wrong, or shout and summon.
American / British English. American English runs for office (stands as a candidate); British English stands for office. This book uses run for office.

This unit shows the system from both sides at once. Across the clinic, one verb stayed still and the particle moved. Here, the particle out stays still and three verbs move it: run out of, call out, work out. Meaning is built from two pieces, verb and particle, and either one can be the variable.

run up: to accumulate a cost or total. Up: it builds up.

call for: to require or demand something. For: it points to a need.

work up: to develop or produce something. Up: build it up from nothing.
